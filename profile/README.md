# 🚀 CDMawa

> **Cloud-Agnostic Application Lifecycle Management (ALM)**

CDMawa is an application lifecycle management platform built in Go. Inspired by the Open Application Model (OAM), CDMawa uses Apple's Pkl for complete application configuration modeling, leveraging imported Terraform and Pulumi components under the hood for declarative infrastructure provisioning.

---

### 🏛️ Projects
* **[`cdmawa`](https://github.com/CDMawa/cdmawa)** — Core ALM engine, Pkl schema evaluator, and multi-cloud provisioning orchestrator.
